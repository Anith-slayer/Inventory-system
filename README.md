# Inventory - System 

This is a simple Python-based inventory management system that helps you manage product data such as item name, quantity, and price. It allows you to add, update, and manage your inventory through a terminal interface.

## Features

- Add new inventory items
- Update existing item quantities
- View all inventory records
- Data stored in an Excel file (`inventory.xlsx`)

##  Files in this Project

- `inv3.py` — Main Python script for the inventory system
- `inventory.xlsx` — Auto-generated Excel file to store data
